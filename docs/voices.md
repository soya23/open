## 時代の変化 (5記事を並べると見える)

2022〜2025前半の価値 =「tmuxの学習コスト回避」。
2026年の価値 =「**複数AIエージェントを並走させる基盤**」。
その基準で zellij から人が離れ始めた理由が、①AIプロセスがセッション復元で
死ぬ、②外部からスクリプトで操作できない、③状態可視化・通知が自作プラグイン
頼み — の3点で、**3つとも zeliji は本体機能として持っている**。

## `zeliji tell` の設計メモ

- `zeliji tell core "先にテストを書いて"` → `.zeliji/bus/control.jsonl` に
  追記 → cockpit が250msごとに配達 (カーソル管理で二重配達なし)
- エージェント自身も使える (charterには載せない)。その場合タイムラインに
  `(qaからの指示)` と送り主が明示されるので、誰が誰を動かしたか常に見える
- これで「Claude Code から zeliji チームを1コマンドで駆動する」が成立する
